# GARON DENISE

GARON DENISE is a local-first Flutter Android app for daily operations work:
lead management, procurement requests, supply ordering, and container tracking.

The app stores records and preferences on the device. It does not use accounts,
network APIs, analytics, advertising SDKs, or Android runtime permissions.

## Release Outputs

Store listing files, privacy policy, screenshots, data safety export, and the
release app bundle are generated under `docs/`. The `web/` folder is a separate
static landing page and is packaged as `web.zip`.
